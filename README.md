# Work efficiency tools

日々のPC作業で繰り返しがちな検索、ファイル整理、アプリ起動を、少ない操作で行うためのWindows向けツール集です。5つのアプリはそれぞれ単独で使えます。必要なものだけ選んでください。
> **これらのアプリは Claude（Anthropic 社の AI）によって生成されました。**

## アプリ一覧

| アプリ | できること・作業が楽になるポイント |
|---|---|
| **FileFinder** | よく使うフォルダーを登録し、ホットキーですぐに開けます。深い階層のフォルダーも、エクスプローラーを何段もたどらず一覧から選んでアクセス。検索ウィンドウもホットキーで呼び出せるので、ファイル名や場所を探す手間を減らします。 |
| **folder_zip_tool** | エクスプローラー、デスクトップ上で選んだ複数の項目を、ホットキーひとつで新しいフォルダーにまとめたり、ZIPにしたりできます。手作業でフォルダーを作ってファイルを移す、圧縮ソフトを開いて項目を登録する、といった繰り返しを短縮します。 |
| **preset_launcher** | 作業ごとに使うアプリの組み合わせをプリセットとして登録し、まとめて起動できます。アプリごとに引数や作業フォルダー、ウィンドウ状態も指定でき、仕事を始めるたびに複数のアプリや画面を整える手間を減らします。 |
| **py_maneger** | `.bat`や`.vbs`から起動するアプリをひとつの一覧で管理し、起動・停止できます。よく使うアプリにはホットキーも設定できるため、起動用ファイルを探し回らず、複数の自作ツールをまとめて扱えます。 |
| **Quick Sorter** | ダウンロードやデスクトップに散らばったファイルを一覧で確認し、移動先フォルダーを検索・選択してすばやく整理できます。移動履歴に基づく候補表示もあるため、毎回フォルダーを探す手間を減らし、ファイルの置き場所を整えやすくします。 |

各アプリの要件や起動方法は、それぞれのフォルダーにあるREADMEを参照してください。

## 自分の使い方に合わせてカスタマイズ

各アプリのソースコードをもとに、ChatGPTやClaudeを使って自分の作業に合わせた変更を加えられます。たとえば、ホットキーや画面表示の変更、操作手順の調整、起動するアプリや整理ルールの追加などができます。変更内容を伝えるときは、対象ファイルと希望する動作を具体的に示してください。

このツール集に含まれるアプリは、ChatGPTおよびClaudeを利用して作成しました。

## 必要環境

- Windows 10/11
- Python 3（必要なバージョンや追加パッケージはアプリによって異なります）
- 詳細は各アプリのREADMEを参照してください。

## 注意

これらのツールはファイル名、フォルダーの場所、起動設定など、PC内の情報を扱います。Quick Sorterとfolder_zip_toolはファイルを移動するため、操作前に対象と移動先を確認してください。公開・共有時は個人用の設定ファイル、ログ、`__pycache__`、`*.pyc`を含めないでください。
