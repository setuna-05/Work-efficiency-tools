# Pythonアプリ管理

指定したフォルダーにある`.bat` / `.vbs`起動ファイルを登録し、起動・停止するWindows用デスクトップアプリです。

## 主な機能

- 起動ファイルの登録、表示名の編集、登録解除
- 登録したアプリの起動・停止
- Ctrl / Alt / Shiftと英数字またはF1～F12を組み合わせた起動ホットキー
- 起動状態の表示
- Python標準ライブラリのTkinterを使用（追加パッケージ不要）

停止操作は管理アプリが特定できるプロセスを終了します。VBSなどが別の方法で子プロセスを起動する場合、停止できないことがあります。

## 必要環境

- Windows
- Python 3
- Tkinter

## 起動

`起動する.vbs`をダブルクリックします。コマンド画面を表示して起動したい場合は`起動する.bat`も使えます。

「フォルダーを追加」から管理対象を登録してください。選んだフォルダーの直下に起動ファイルが1つなら自動登録され、複数ある場合は選択できます。

## 設定

登録内容は`%LOCALAPPDATA%\PythonAppManager\apps.json`、ホットキーなどの設定は同フォルダー内に保存されます。登録したフォルダーのパスが含まれるため、共有前に確認してください。
