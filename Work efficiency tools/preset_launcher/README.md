# プリセットランチャー

作業内容ごとに起動するアプリの組み合わせを保存し、まとめて起動するWindows用ランチャーです。

## 主な機能

- プリセットの作成・編集・削除
- 実行ファイル、ショートカット、コマンド、URLなどの登録
- 起動時の引数、作業フォルダー、ウィンドウ状態（通常・最小化・最大化）の設定
- プリセット内のアプリをまとめて起動
- 対象アプリへの通常終了要求
- Windows起動時にランチャーや指定プリセットを起動
- GUIなしで一覧表示、プリセット起動、ドライランを実行

終了要求に対応するのは主に`.exe`と`.lnk`です。URLやスクリプトなど、対象ウィンドウを特定できない登録は終了操作の対象外です。アプリによっては指定したウィンドウ状態が反映されないことがあります。

## 必要環境

- Windows 10/11
- Python 3.8以降
- Tkinter（python.orgの標準インストーラーに含まれます）

追加のPythonパッケージは不要です。

## 起動

```powershell
pyw preset_launcher.py
```

「新規」でプリセットを作り、アプリを登録してから一覧のプリセットをダブルクリックします。起動時の自動実行を設定する場合は、`startup_preset_launcher.bat`へのショートカットをWindowsのスタートアップフォルダーに登録します。

## コマンドライン

```powershell
pyw preset_launcher.py --list
pyw preset_launcher.py --run "プリセット名"
py preset_launcher.py --run "プリセット名" --dry-run
```

## 設定

設定は`%APPDATA%\PresetLauncher\presets.json`に保存されます。登録したアプリのパスや引数が含まれるため、設定ファイルを共有する際は内容を確認してください。
