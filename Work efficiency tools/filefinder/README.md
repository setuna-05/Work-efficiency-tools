# FileFinder

Windowsの検索インデックスを使ってファイルを探し、すばやく開くためのデスクトップランチャーです。登録したフォルダー内だけを検索するか、インデックス対象全体を検索できます。

## 主な機能

- `Ctrl+Alt+R`で検索ウィンドウを表示（設定から変更可能）
- 検索対象フォルダーの登録・選択・解除
- Windows検索インデックスを使った全体検索
- 検索結果を開く、パスをコピーする、格納フォルダーを開く
- `Alt+1`～`Alt+9`、ダブルクリック、Enterで登録フォルダーを開く
- 登録フォルダーごとのグローバルホットキー設定
- タスクトレイ常駐、動作ログの保存

検索結果はWindowsのインデックス設定に依存します。インデックスに含まれない場所や項目は、全体検索で見つからない場合があります。

## 必要環境

- Windows
- Python 3
- PySide6
- pywin32

## 起動

1. Pythonをインストールします。
2. このフォルダーで次を実行します。

```powershell
py -m pip install -r requirements.txt
```

3. `FileFinder_start.vbs`をダブルクリックします。

## 設定とログ

設定とログは`%APPDATA%\FileFinder\`に保存されます。登録フォルダーのパスや検索時の情報が設定・ログに含まれることがあります。共有する場合は内容を確認してください。
