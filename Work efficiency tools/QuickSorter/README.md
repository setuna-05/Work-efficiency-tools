# Quick Sorter

ダウンロードフォルダーとデスクトップ直下のファイルを確認し、ダウンロード内のフォルダーへ整理するWindows用ツールです。

## 主な機能

- ダウンロードとデスクトップ直下のファイル一覧表示
- ダウンロード内のフォルダーを移動先として選択
- フォルダー名の検索と階層ツリー表示
- 過去の移動履歴から移動先候補を表示
- `Ctrl+Alt+M`で呼び出し（設定で変更可能）
- Windows起動時の自動起動の登録・解除

Quick Sorterはファイルを移動します。実行前に対象ファイルと移動先を確認してください。

## 必要環境

- Windows
- Python 3.8以降
- Tkinter（標準ライブラリ）

## 起動

`start_sorter.bat`をダブルクリックします。Pythonから直接起動する場合：

```powershell
pyw quick_sorter.py
```

## 設定と履歴

設定、移動履歴、ログは`%APPDATA%\FileEditor\`に保存されます。履歴にはファイル名や移動先が含まれるため、共有する場合は内容を確認してください。
