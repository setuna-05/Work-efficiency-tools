# フォルダ化 / ZIP化ツール

エクスプローラーで選択したファイルやフォルダーを、ショートカットキーでまとめるWindows用タスクトレイアプリです。

## 主な機能

| 操作 | 初期ショートカット | 動作 |
|---|---|---|
| フォルダ化 | `Ctrl+Alt+F` | 新しいフォルダーを作り、選択項目をそこへ移動 |
| ZIP化 | `Ctrl+Alt+Z` | 選択項目をZIPへコピー（元の項目は残る） |

- ショートカットキーの変更
- 実行時に名前を確認する設定
- ZIP作成後に作業フォルダーを残す設定
- Windows起動時の自動起動
- 同名フォルダー・ZIPには連番を付与

## 必要環境

- Windows
- Python 3.9以降
- `pywin32`, `pystray`, `Pillow`

## 起動

1. Pythonをインストールします。
2. `setup.bat`を実行して依存パッケージをインストールします。
3. `run.bat`を実行します。アプリはタスクトレイに常駐します。
4. エクスプローラーで項目を選び、ショートカットキーを押して操作します。

`build_exe.bat`を実行すると、PyInstallerで実行ファイルをビルドできます。

## 注意

「フォルダ化」は選択項目を移動します。ZIP化は元の項目を残してコピーします。デスクトップ上の選択項目の検出には制限があるため、うまく動かない場合はエクスプローラーで操作してください。他のアプリが使っているショートカットキーは登録できません。

設定は`%APPDATA%\FolderZipTool\config.json`に保存されます。
